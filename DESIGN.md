# DESIGN — Mobile Suit // BuccKyy

Design system distilled from the official *Mobile Suit Gundam: Hathaway's Flash*
site (`https://gundam-official.com/hathaway/`) and rebuilt as an original,
self-hosted GitHub profile.

No official artwork, logo, typeface file, or asset from the site is redistributed.
The palette, layout grammar, and typographic behaviour are referenced; the
mecha artwork, HUD, and all lettering here are original vector work.

## Tokens

| Token | Value | Use |
|:--|:--|:--|
| `void` | `#020305` | page / panel field |
| `navy` | `#00041C` | deep panel, stats field |
| `steel` | `#27455C` | hairlines, inactive data |
| `steel-hi` | `#8FA3B5` | panel edges, micro labels |
| `mist` | `#EAEAEA` | primary text (the site's body colour) |
| `dim` | `#7C8AA0` | secondary data |
| `periwinkle` | `#AEB8F0` | CTA discs, active accents |
| `cyan` | `#00A0E9` | hologram / sensor glow |
| `cyan-hot` | `#7FE7FF` | lit edges, eye / visor core |
| `gold` | `#C8A44D` | V-fin, warning marks |
| `crimson` | `#8E2F3C` | chin / crest plate |

Type sampled from the site:

- Display: **Barlow Condensed** 300–600, wide tracking (`0.06–0.2em`), all caps.
- Data / HUD: **IBM Plex Mono** 400, `0.1–0.2em` tracking.
- Japanese accents: **Shippori Mincho** (Mincho-serif register), `0.25–0.4em` tracking.
- Section titles are underscore-prefixed (`_PILOT`), 34 px at 1000 px width,
  followed by a gradient hairline; Japanese label + `SEC. 0x` sit flush right.

## Motifs

- Cropped, cinematic mecha close-up instead of a full illustration.
- CRT scanline overlay at 3.5–5% white; slow drift.
- Hairline HUD frame with corner brackets.
- Ghost model code (`MS-01`) at 3–5% opacity, as on the official MECHA cards.
- Round periwinkle CTA discs with condensed caps + Japanese micro-label.
- Telemetry panel is generated from real GitHub data; no rate-limited cards.

## Assets

| File | Purpose |
|:--|:--|
| `assets/hero.svg` | animated hero, all text outlined |
| `assets/sec-0x-*.svg` | section headers (dark strip, readable in light/dark themes) |
| `assets/cta-repos.svg` / `cta-contact.svg` | round CTA discs |
| `assets/telemetry.svg` | generated by `tools/telemetry.py` + GitHub Actions |
| `assets/footer-hud.svg` | signal-trace footer |

All SVGs are self-hosted and contain no scripts, external fonts, or external
images. Animation uses CSS only and respects `prefers-reduced-motion`.

## Regenerate telemetry

```bash
GITHUB_TOKEN=$(gh auth token) python3 tools/telemetry.py
```

The workflow at `.github/workflows/telemetry.yml` runs daily and commits the SVG
when the data changes.
